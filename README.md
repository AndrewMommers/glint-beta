# Glint: closed beta

Builds of **Glint**, a glassy color-matching card game, for invited testers.

- Download the latest installer from **[Releases](https://github.com/AndrewMommers/glint-beta/releases/latest)**.
- You need an invite code to create an online account.
- Singleplayer and the Campaign also work offline.

This repository only holds builds, no source code.
